# ClimateLens
ClimateLens is a weather dashboard project I built using HTML, CSS, JavaScript, OpenWeather API, and Chart.js. The main idea of this project was to create a modern looking weather website that can show live weather details and simple analytics in a clean UI.

## Features
* Live weather updates
* Search weather by city name
* Temperature, humidity, wind speed, and condition display
* Weather analytics chart using Chart.js
* Responsive frontend design
* Multi-page navigation

## Technologies Used
* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeather API
* Chart.js

## About The Project
I built this project to improve my frontend development skills and understand how API integration works in real projects. While building ClimateLens, I learned about fetching live data, DOM manipulation, responsive design, and handling real-time weather information dynamically.
